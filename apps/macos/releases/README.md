# 卡包 · Mac 版

卡包 Mac 版的官方下载与更新页面。

## 下载

前往 [最新版本](https://github.com/yuangy1995/card-wallet-releases/releases/latest)，下载 `CardWallet-*.zip`，解压后将「卡包.app」放入「应用程序」文件夹。

需要 macOS 14 或更新版本。Apple Silicon（M 系列）请选择文件名含 `arm64` 的安装包，Intel Mac 请选择含 `x86_64` 的安装包。芯片类型可在苹果菜单「关于本机」中查看。

## 首次打开

此应用未经过 Apple 公证。首次打开时，如果 macOS 阻止运行，请先确认安装包来自本仓库，再按照系统提示在「系统设置 → 隐私与安全性」中选择「仍要打开」。不要关闭系统的全局安全保护。

## 检查更新

2026 年 9 月 14 日起以 1.0.0 作为正式公开首发版本。使用此前早期安装包的用户，请先备份数据、退出卡包，再手动下载并替换应用；不要删除卡包数据文件。安装此次正式版后，后续更新可通过应用内入口完成。

打开「设置 → 软件更新」，点击「检查更新…」；也可从应用菜单检查更新。卡包会定期检查新版本，安装前由你确认。

此仓库仅用于分发安装包、更新清单及版本说明。
