# Android 卡包 UI v2 验收

## 安装预览包

在 `apps/android` 目录运行：

```sh
bash gradlew :app:assembleDebug -PwalletPreview=true
```

预览包名称为「卡包预览」，包名为 `com.applist.cardwallet.preview`。正式包仍为 `com.applist.cardwallet`，应用标识、签名和数据位置均不变。预览包可与正式版并存，不要为了安装预览包卸载正式应用。

预览包拥有独立本地数据。首次打开卡包为空，不会读取或迁移另一应用的卡片、星标、密钥和同步配置。自动化截图中的 115 张卡均为测试夹具，不会预置在 APK 内。预览包采用 Debug 签名，不是发布渠道更新包；不同构建环境的 Debug 签名可能不同。

**本地隔离不等于云端隔离。** 配置完成后自动双向同步始终启用。测试同步时优先使用独立 WebDAV 目录或云端副本；使用正式同步目录前先备份，预览包中的修改也可能同步到该目录和其他客户端。默认仍只在 Wi-Fi 下自动同步；允许流量后，移动数据下手动同步仍会征求确认。未配置账号和密钥时不会启动同步。

## 人工验收

- 首页卡片与列表切换、搜索、信用卡/储蓄卡分类、右侧固定星标、分组/排序与批量操作都应可用。长列表按可见范围加载，中间卡片下缘被覆盖，仅最后一张完整收尾。
- 卡面和列表应无额外白色 Logo 底板，Amex、Capital One 等长宽比保持原样。深色列表采用更清晰的标识版本。未知/歧义名称保持缩写，而不是借用其他银行 Logo。
- 无卡片时只有一个添加按钮；筛选无结果时可「查看全部卡片」。卡片提醒使用小型浮动铃铛及数量，不占一整行横幅。
- 详情页保留复制、显示/隐藏、5 秒自动隐藏卡号/CVV、编辑和附件入口。号码独占一行，16—19 位号码按空间缩放，不能因图标挤压换行。
- 主题选择的勾选标记位于右上角，不另占一行。检查浅色、深色、320dp 小屏、大字体、横屏及连续滚动的实际设备体验。
- 同步状态和配置表单没有关闭自动同步的开关。取消编辑不应保存草稿；连接测试不等于校验同步密钥。旧版明确关闭的配置会迁移为开启，同时保留账号、加密后的密码/密钥和网络偏好。

## 自动化与性能边界

```sh
bash gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug --continue --max-workers=2
```

`WalletV2VisualTest` 使用真实 Compose 组件及 Robolectric Native Graphics 生成 `app/build/outputs/ui-review/` 中的 PNG。测试包含 115 张虚构卡片的首屏/末张、两种视图、浅/深色、320dp 大字体、空卡包、空星标、提醒按钮、19 位卡号、主题和同步配置取消。保留项目原有回归测试。

通过惰性列表、稳定项目键/contentType、有界 Logo 匹配缓存和不触发重组循环的文本自适应减少不必要工作。测试检查可见/预取卡片数量，但这不是物理设备帧率、耗电或端到端同步性能测量；这些仍需真机验收。

日期 API 使用 core library desugaring 兼容 minSdk 23，网络回调保留 API 23 分支，通知发送处理权限撤销。没有关闭 Lint、增加全局抑制或隐藏错误。

## 覆盖与兼容性

当前离线目录包含 **374 个银行/发卡机构标识条目和 7 类卡组织标识**。详细清单及来源见 `branding/COVERAGE.md`、`branding/catalog.json` 与 `branding/README.md`。目录含历史机构名称，数量不代表所有在营银行均已覆盖；不能据此宣称「大陆全部」或「全球全部」。

匹配支持中英文常见别名、大小写、部分繁简体、公司后缀和受限名称匹配，歧义回退。正常构建和应用运行不从第三方下载 Logo，也不上传卡号或银行名称。品牌商标仍属各自权利人。

星标和显示模式是 Android 本机偏好，不跨端同步。本次不修改 SharedCard、SQLite 或 SyncV4 数据格式，也不更改其他客户端代码。
