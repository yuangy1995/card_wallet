# macOS 开工文档

## 1. 项目目标

本项目是 `macOS` 原生客户端，必须使用：

- `Swift`
- `SwiftUI`

允许少量使用 `AppKit` 补足桌面交互，但不能反过来以 `AppKit` 为主。

## 2. 核心定位

- 桌面高效率管理端
- 体验接近 web，但实现必须是原生
- 强化快捷键、拖拽、侧边栏、多窗口潜力

## 3. 架构约束

- `Domain` 不依赖 UI
- `Data` 负责数据库和协议
- `Features` 只消费 ViewModel
- `Platform` 只封装原生能力

## 4. 必须遵守

1. 共享字段不得随意加减
2. 所有导入导出都必须使用本项目 `Docs` 中协议
3. 本地文件路径不能进入共享 JSON
4. 表格展示字段不能反写回共享数据

## 5. 推荐开发顺序

1. 主窗口和导航壳
2. 列表页和详情侧栏
3. 本地 SQLite
4. 导入导出
5. 编辑弹窗
6. 快捷键和拖拽

## 6. 对后续 AI 的要求

- 不要直接照搬 web 组件设计
- 要遵守 macOS 桌面习惯
- 列表页允许高密度信息
- 文档变更先于协议变更
