### 字段 9: `limit` - 信用额度

#### 基本信息
| 属性 | 值 |
|------|-----|
| **字段名** | limit |
| **中文名** | 信用额度 |
| **类型** | Number |
| **必填** | ✅ 是 |
| **默认值** | 0 |
| **最小值** | 0 |
| **最大值** | 无限制（建议不超过10000000） |

#### 单位说明
额度的货币单位由 `type` 字段决定：

```javascript
formatCurrency(100000, 'JPY')  // ¥100,000
```

#### 统计计算
```javascript
// 计算总额度（考虑共享）
function calculateTotalLimit(cards) {
  const sharedLimits = new Map()  // key: country-bank, value: limit
  let totalLimit = 0
  
  cards.forEach(card => {
    if (card.isSharedLimit) {
      const key = `${card.country}-${card.bank}`
      if (!sharedLimits.has(key)) {
        sharedLimits.set(key, card.limit)
        totalLimit += card.limit
      }
    } else {
      totalLimit += card.limit
    }
  })
  
  return totalLimit
}
```

### 字段 11: `isSharedLimit` - 银行额度共享 ⭐ v2.0新增

#### 基本信息
| 属性 | 值 |
|------|-----|
| **字段名** | isSharedLimit |
| **中文名** | 是否共享额度 |
| **类型** | Boolean |
| **必填** | ✅ 是 |
| **默认值** | true |
| **v2.0** | 新增字段 |

#### 业务含义
同一银行发行的多张信用卡，额度可能是共享的（共用一个总额度），也可能是独立的。

#### 实际案例
```
场景1: 共享额度 (isSharedLimit = true)
招商银行 VISA金卡    额度: 50000
招商银行 银联白金卡  额度: 50000
→ 这两张卡共享50000额度，而不是各自50000

场景2: 独立额度 (isSharedLimit = false)
招商银行 VISA金卡    额度: 50000 (独立)
招商银行 银联白金卡  额度: 80000 (独立)
→ 总计130000额度
```

#### 自动检测逻辑
```javascript
// src/components/dialog/CreditCardDialog.vue
// 当用户选择"共享额度"时，自动检测同银行已有卡片

const checkExistingSharedLimit = () => {
  const currentCountry = formData.value.country
  const currentBank = formData.value.bank
  
  // 查找同国家同银行的已有卡片
  const existingCard = existingCards.find(card => {
    const cardBank = card.bank
    return card.country === currentCountry && 
           cardBank === currentBank && 
           card.isSharedLimit === true &&
           card.id !== formData.value.id
  })
  
  if (existingCard) {
    // 自动使用已有卡片的额度和币种
    formData.value.limit = existingCard.limit
    formData.value.type = existingCard.type
    
    ElMessage.info(
      `检测到您已有${currentBank}的卡片，额度和币种已自动同步为：${formatCurrency(existingCard.limit, existingCard.type)}`
    )
  }
}
```

### 字段 12: `accountBillDate` - 账单日 ⭐ v2.0类型变更

#### 基本信息
| 属性 | 值 |
|------|-----|
| **字段名** | accountBillDate |
| **中文名** | 账单日 |
| **类型** | String (v2.0从Number改为String) |
| **必填** | ❌ 否 |
| **格式** | "1" - "31" |
| **默认值** | '' (空字符串) |

#### ⚠️ 重要类型变更
**v1.0格式** (已废弃):
```javascript
accountBillDate: 5      // Number类型
accountBillDate: 25     // Number类型
```

**v2.0格式** (当前):
```javascript
accountBillDate: "5"    // String类型
accountBillDate: "25"   // String类型
```

#### 业务含义
每月固定日期，银行生成账单的日期。例如账单日为5号，则银行会在每月5号统计上个账单周期的消费。

#### 账单周期示例
```
账单日: 5号
还款日: 25号

周期1: 3月6日 - 4月5日  → 4月25日还款
周期2: 4月6日 - 5月5日  → 5月25日还款
```

#### 验证规则
```javascript
// 可选字段
if (card.accountBillDate) {
  // 必须是String类型
  if (typeof card.accountBillDate !== 'string') {
    throw new Error('accountBillDate必须是字符串类型')
  }
  
  // 值范围验证
  const day = parseInt(card.accountBillDate, 10)
  if (isNaN(day) || day < 1 || day > 31) {
    throw new Error('账单日必须在1-31之间')
  }
}
```

#### 免息期计算
账单日配合 `billingDaySpendingToNextBill` 字段，用于计算免息期：

```javascript
// src/components/table/CreditCardTable.vue
// 计算距离还款日的天数（免息期）

function calculateInterestFreeDays(card) {
  const today = new Date()
  const currentDay = today.getDate()
  const billingDay = parseInt(card.accountBillDate, 10)
  const dueDay = parseInt(card.dueDate, 10)
  
  let days = 0
  
  if (currentDay === billingDay) {
    // 账单日当天
    if (card.billingDaySpendingToNextBill) {
      // 计入下期，免息期最长
      days = calculateDaysToNextDue(today, dueDay) + 30
    } else {
      // 计入当期，免息期最短
      days = calculateDaysToNextDue(today, dueDay)
    }
  } else if (currentDay < billingDay) {
    // 当前账单周期内
    days = calculateDaysToNextDue(today, dueDay)
  } else {
    // 下个账单周期
    days = calculateDaysToNextDue(today, dueDay) + 30
  }
  
  return days
}
```

### 字段 13: `dueDate` - 还款日 ⭐ v2.0类型变更

#### 基本信息
| 属性 | 值 |
|------|-----|
| **字段名** | dueDate |
| **中文名** | 还款日 |
| **类型** | String (v2.0从Number改为String) |
| **必填** | ❌ 否 |
| **格式** | "1" - "31" |
| **默认值** | '' (空字符串) |

#### 业务含义
每月固定日期，必须还清账单金额的最后期限，超过此日期将产生利息和滞纳金。

#### 与账单日的关系
```
一般规则: 还款日 = 账单日 + 18~25天

示例:
账单日: 5号
还款日: 25号
间隔: 20天

常见搭配:
1号账单 → 20号还款
5号账单 → 25号还款
10号账单 → 30号还款 (或次月5号)
```

#### 验证规则
```javascript
// 可选字段
if (card.dueDate) {
  // 必须是String类型
  if (typeof card.dueDate !== 'string') {
    throw new Error('dueDate必须是字符串类型')
  }
  
  // 值范围验证
  const day = parseInt(card.dueDate, 10)
  if (isNaN(day) || day < 1 || day > 31) {
    throw new Error('还款日必须在1-31之间')
  }
  
  // 逻辑验证（可选）
  if (card.accountBillDate) {
    const billDay = parseInt(card.accountBillDate, 10)
    const dueDay = parseInt(card.dueDate, 10)
    
    // 还款日通常在账单日之后10-25天
    const diff = dueDay >= billDay ? dueDay - billDay : dueDay + 30 - billDay
    
    if (diff < 10 || diff > 25) {
      console.warn('还款日与账单日间隔异常:', diff, '天')
    }
  }
}
```

#### 自动提醒
```javascript
// 检查即将到期的还款
function checkDuePayments(cards) {

  const warnings = []
  
  cards.forEach(card => {
    if (card.dueDate) {
      const daysUntilDue = calculateDaysUntilDue(today, card.dueDate)

  })
  
  return warnings
}
```

### 字段 14: `billingDaySpendingToNextBill` - 账单日消费计入规则 ⭐ v2.0新增

#### 基本信息
| 属性 | 值 |
|------|-----|
| **字段名** | billingDaySpendingToNextBill |
| **中文名** | 账单日消费计入下期账单 |
| **类型** | Boolean |
| **必填** | ✅ 是 |
| **默认值** | true |
| **v2.0** | 新增字段 |

#### 业务含义
决定账单日当天的消费计入当期账单还是下期账单，直接影响免息期长短。

#### 两种规则对比
```
规则A: billingDaySpendingToNextBill = true (计入下期)
账单日: 5号
还款日: 25号

4月5日消费1000元 → 计入4月6日-5月5日周期 → 5月25日还款
免息期: 50天 (最长)

---

规则B: billingDaySpendingToNextBill = false (计入当期)
账单日: 5号
还款日: 25号

4月5日消费1000元 → 计入3月6日-4月5日周期 → 4月25日还款
免息期: 20天 (最短)
```

#### 免息期计算影响
```javascript
// src/components/table/CreditCardTable.vue
if (currentDay === billingDay) {
  // 账单日当天消费
  if (card.billingDaySpendingToNextBill) {
    // 计入下期账单，免息期 = 30天 + 还款间隔
    interestFreeDays = 30 + (dueDay - billingDay)
  } else {
    // 计入当期账单，免息期 = 还款间隔
    interestFreeDays = dueDay - billingDay
  }
}
```
