# 四端业务契约 v1

这是应用行为契约与共同测试输入，不是共享运行时。四端分别实现，任何规则变更先修改同一份 fixtures 并通过四端测试；不修改 SyncV4 4.0.0 的写入格式。

## 固定口径

- 缺失 `cardCategory` 按 credit；只有 debit 排除于信用额度、免息期和信用卡提醒。
- 币种 trim + upper-case；空值是未知币种，独立分栏，禁止自动推定 CNY、混币种求和或用金额比例绘制跨币种占比。
- 共享池按 trim 后的地区、去括号说明/空白并忽略大小写的银行名称、币种组成。每池取最大非负有限额度；独立卡累加。金额在每张卡上以两位小数四舍五入后累加。银行展示别名与业务合并规则分离，不用 Logo 猜测银行身份。
- 免息期指“今天消费至对应还款日的日历天数”，不是最长免息期。采用设备时区中的公历日期。账单日裁剪到实际月末；账单日当天是否计入下期由原字段控制；还款日名义数字小于或等于账单日则在账单次月，亦按实际月末裁剪。无效配置返回 -1。
- 每月还款提醒必须包含上月账单的本月还款日；账单提前 3 天、还款提前 7 天，含当天。
- 有效期按月，整个月均有效；次月一日起过期。未来 6 个月（含边界月）为即将到期。支持 MM/YY、MM/YYYY、YYYY-MM 和有效的 YYYY-MM-DD；不接受日期溢出。
- 年费天数按日历日计算。非终免状态在前 60 天提醒，到期日归 overdue；保留原有到期后 60 天内的提醒窗口。确认达标按已存日期加一个公历年，闰日裁剪；重复确认尚未进入下一提醒周期时不再次推进。储蓄卡不执行年费动作。
- SyncV4：解析时间后较新记录优先，同时间删除优先，同时间/状态按 mutationId 字典序；不同 cardId 即使卡号相同也不自动合并。合并须可交换、幂等。新本地修改时间必须严格晚于该卡已观察事件。
- 收藏是本机展示偏好，不写入 SharedCard，不更新卡片修改时间；仅真正删除卡片时清理收藏。搜索、分页与分类切换不能误清理收藏。

## 验证

Web `src/utils/platformContract.test.js`、Android `PlatformContractTest.kt`、Apple 两端 `PlatformContractTests.swift` 从本目录读取相同 JSON。时区由测试环境设置；CI 运行 UTC 与 America/Los_Angeles 的核心检查。样例无真实卡片或账号。

所有客户端仍保留自己的原生界面和构建。修改 iOS/macOS 工程配置后使用原有 XcodeGen 生成工程；Android 测试资源和 Apple 测试 bundle 引用同一目录，不维护四份测试数据副本。

## 编辑、收藏与本地安全

- 收藏仅保存在本机；列表筛选、分页、锁定和加载期间不清理收藏，只有已提交的删除标记可以清理。SharedCard/SyncV4 不增加收藏字段。
- 批量操作只影响选择的 ID；明确的下一年费日期优先于自动推进一年；终免不保留待收取日期；储蓄卡不执行年费动作，但不擦除保留的历史信用字段。
- 卡片及图片的未知 JSON 字段随编辑、数据库和同步往返保留；旧显示状态和已废弃的身份别名不参与同步。不能把无法解析的附件静默改成空列表。
- 新增附件最多 12 张，每个源文件至多 10 MiB，生成最长边 1600px 的 JPEG；已有或远端超过上限的附件不截断。这是录入边界，不是缩减云端数据的规则。
- 本地数据保护与云端 SyncV4 密码分离。Android 新数据由 AndroidKeyStore 的设备密钥保护；Mac 使用既有本机凭证库中的随机密钥；iOS 继续使用钥匙串本地密钥；Web 使用密码派生的本地保险库。各端锁定后卸载敏感视图、取消同步，不提供“已发送写入可撤回”保证。
- Android 数据库版本升级到 5，旧明文行与账本在同一升级事务中加密。迁移失败回滚，待上传标记和修改版本同本地变更一起落库。设备密钥不参与系统迁移，系统备份/设备传输排除本地库，跨设备恢复使用原 WebDAV 同步密钥。
- macOS 的新 cards.json/同步账本采用随机密钥 AES-GCM；兼容读取旧固定口令文件，仅在成功保存后替换。任何原生端无法读取现有账本时不重新种入空账本、不启动会覆盖它的同步。

`batch-operations.json` 与 `image-roundtrip.json` 是共享输入。运行器必须实际调用各端生产模型和编辑函数；仅验证 JSON 文件格式不算通过业务契约。
