# 信用卡管理系统

一个基于 Vue.js 的现代化信用卡管理系统，帮助用户高效管理多张信用卡信息。

## 功能特性

### 信用卡管理
- ✨ 新增、编辑、删除信用卡信息
- 🔒 支持卡号和 CVV 的显示/隐藏功能（使用 AES 加密）
- 📋 查看信用卡详细信息
- 🔍 强大的搜索和筛选功能（支持多条件组合查询）
- 🔄 表格支持自定义排序
- ⏱️ 自动计算每张卡的免息期

### 数据管理
- 📤 导出加密的信用卡数据（支持自定义密码）
- 📥 导入加密的信用卡数据
- ☁️ WebDAV 云端备份和恢复
- 💾 本地自动备份（每次修改后1分钟自动备份，保留最近50条记录）
- 🔄 支持本地备份数据预览和恢复
- 🗑️ 数据清除功能
- 🎲 支持生成随机测试数据
- 💾 自动保存到本地存储

### 年费管理
- ⏰ 自动检测年费情况
- ✅ 手动检查年费状态
- 📝 年费达标状态标记
- 🔄 自动检测临近年费收取时间的卡片
- ⚡ 距离上次提额天数自动计算
- 📅 自动计算每张卡的免息期天数
- 🎯 智能提醒年费达标状态更新

### 数据分析
- 📊 信用卡使用统计分析
- 📈 可视化数据展示
- 📑 自定义表格显示列
- 🎯 卡片状态高亮显示

## 技术栈

- Vue.js 3 - 前端框架
- Element Plus - UI 组件库
- Crypto-js - 数据加密
- WebDAV - 云端备份
- LocalStorage - 数据持久化
- Vite - 构建工具
- SCSS - 样式预处理器

## 安装

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build
```

## 使用指南

### 基本操作
1. 添加信用卡：点击"新增信用卡"按钮，填写信用卡信息
2. 编辑信用卡：在表格中点击编辑按钮修改信息
3. 删除信用卡：在表格中点击删除按钮移除信用卡
4. 查看详情：点击表格中的查看详情按钮
5. 右键菜单：支持表格行右键快捷操作
6. 免息期计算：系统会根据账单日和还款日自动计算每张卡的免息期
   - 需要设置账单日和还款日才能计算免息期
   - 免息期 = 还款日期 - 当前日期
   - 账单日当天的消费按当期账单计算
   - 自动处理月末日期（如2月份）的特殊情况

### 数据管理
- 导出数据：点击"导出数据"按钮，将所有信用卡信息导出（支持加密保护）
- 导入数据：点击"导入数据"按钮，导入已有的信用卡信息（支持加密文件）
- 云端备份：支持通过 WebDAV 服务器进行云端备份和恢复
- 本地备份：
  - 自动备份：每次数据修改后1分钟自动创建备份
  - 手动备份：点击"本地备份"按钮查看和管理备份
  - 备份记录：显示备份时间、状态和信用卡数量
  - 数据预览：支持查看备份内容，并显示与当前数据的差异
  - 数据恢复：可以随时恢复到任意备份版本
- 清除数据：点击"清除所有数据"按钮（请谨慎使用）
- 数据格式：支持 JSON 格式的数据导入导出

### 年费管理
- 系统会自动检测即将到期的年费
- 可以手动检查年费情况
- 支持标记年费达标状态
- 自动检测临近年费收取时间的卡片（60天内）
- 智能提醒是否需要更新年费达标状态
- 自动计算距离上次提额的天数
- 支持一键将临近年费收取时间的卡片更新为未达标状态

### 数据分析
- 点击"统计分析"查看信用卡使用情况
- 支持自定义表格显示列
- 提供多维度的数据分析视图
- 表格支持多字段排序

## 数据安全

- 所有数据存储在浏览器的 LocalStorage 中
- 敏感信息（如卡号、CVV）使用 AES 加密存储
- 导出数据支持自定义密码加密
- 请定期导出备份重要数据
