# 信用卡管理系统

一个基于 Vue.js 的现代化信用卡管理系统，帮助用户高效管理多张信用卡信息。

## 功能特性

### 信用卡管理
- ✨ 新增、编辑、删除信用卡信息
- 🔒 支持卡号和 CVV 的显示/隐藏功能
- 📋 查看信用卡详细信息
- 🔍 强大的搜索和筛选功能

### 数据管理
- 📤 导出信用卡数据
- 📥 导入信用卡数据
- 🗑️ 数据清除功能
- 🎲 支持生成随机测试数据

### 年费管理
- ⏰ 自动检测年费情况
- ✅ 手动检查年费状态
- 📝 年费达标状态标记

### 数据分析
- 📊 信用卡使用统计分析
- 📈 可视化数据展示
- 📑 自定义表格显示列

## 技术栈

- Vue.js - 前端框架
- Element Plus - UI 组件库
- LocalStorage - 数据持久化
- Vite - 构建工具

## 安装

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build
```

## 使用指南

### 基本操作
1. 添加信用卡：点击"新增信用卡"按钮，填写信用卡信息
2. 编辑信用卡：在表格中点击编辑按钮修改信息
3. 删除信用卡：在表格中点击删除按钮移除信用卡
4. 查看详情：点击表格中的查看详情按钮

### 数据管理
- 导出数据：点击"导出数据"按钮，将所有信用卡信息导出
- 导入数据：点击"导入数据"按钮，导入已有的信用卡信息
- 清除数据：点击"清除所有数据"按钮（请谨慎使用）

### 年费管理
- 系统会自动检测即将到期的年费
- 可以手动检查年费情况
- 支持标记年费达标状态

### 数据分析
- 点击"统计分析"查看信用卡使用情况
- 支持自定义表格显示列
- 提供多维度的数据分析视图

## 数据安全

- 所有数据存储在浏览器的 LocalStorage 中
- 敏感信息（如卡号、CVV）支持显示/隐藏功能
- 请定期导出备份重要数据
